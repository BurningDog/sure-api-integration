# Sure API Integration

TypeScript scripts for integrating with the [Sure](https://github.com/we-promise/sure) personal finance API.

## Setup

### 1. Install dependencies

```bash
cd src
npm install
```

### 2. Configure environment

```bash
cp src/.env.local.example src/.env.local
```

Edit `src/.env.local` with your values:

```env
apiKey=your_api_key_here
apiUrl=http://localhost:3000
```

Generate an API key from your account settings in the Sure app. For production, set `apiUrl` to `https://app.sure.am`.

## Scripts

All scripts are run from inside the `src/` directory.

### Transactions

Fetches all transactions and writes a timestamped CSV file to the current directory.

```bash
npm run transactions
```

**Options:**

| Flag                        | Description                                         |
| --------------------------- | --------------------------------------------------- |
| `--reverse`                 | Reverse the order (oldest first)                    |
| `--split-income-and-expenses` | Add separate `income` and `expense` columns       |
| `--account-name <name>`     | Filter to a single account by exact name            |
| `--json`                    | Print JSON to stdout instead of writing a CSV       |

**Preset npm scripts:**

| Script                      | What it does                                                              |
| --------------------------- | ------------------------------------------------------------------------- |
| `transactions`              | All transactions, newest first, single `amount` column                    |
| `transactions-json`         | All transactions as JSON to stdout                                        |
| `transactions-all`          | All transactions, oldest first, split income/expense columns              |
| `transactions-business`     | "Business account" only, oldest first, split income/expense columns       |
| `transactions-savings`      | "32 Day Flexi Notice" only, oldest first, split income/expense columns    |

### CSV output columns

`id`, `date`, `name`, `amount`, `currency`, `classification`, `notes`, `account_id`, `account_name`, `account_type`, `category_id`, `category_name`, `merchant_id`, `merchant_name`, `tags`, `created_at`, `updated_at`

When `--split-income-and-expenses` is used, `income` and `expense` columns are added after `amount`.

## API reference

See [API.md](API.md) for full endpoint documentation, or browse the interactive docs at `http://localhost:3000/api-docs` when running locally.

A [Postman collection](sure-api.postman_collection.json) is also included for manual API exploration. The Postman collection was generated by inspecting the [0.6.9 release of Sure](https://github.com/we-promise/sure/releases/tag/v0.6.9).
